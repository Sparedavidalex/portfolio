Repositório contendo o código-fonte do meu portfólio pessoal, desenvolvido para apresentar minha trajetória, habilidades técnicas e projetos na área de Infraestrutura, Cloud Computing e Automações.

## 🚀 O Projeto

O objetivo deste projeto foi criar uma vitrine técnica limpa, responsiva e com alta performance, focada na experiência do usuário e em um design que remete ao ambiente de linha de comando e terminais (Dark Mode).

### 🛠️ Tecnologias Utilizadas no Desenvolvimento
O projeto foi construído "na unha", sem a dependência de frameworks pesados, garantindo carregamento rápido e total controle sobre o DOM:
- **HTML5:** Semântica e acessibilidade.
- **CSS3:** Variáveis nativas (`:root`), Flexbox, CSS Grid, media queries para responsividade e animações avançadas (keyframes e hovers).
- **JavaScript (Vanilla):** Manipulação de DOM para menu mobile, scroll reativo (reveal) e efeito de máquina de escrever (Typewriter).
- **Hospedagem:** GitHub Pages.

## ⚙️ Funcionalidades e UI/UX
- **Typewriter Effect:** Simulação de terminal na seção Hero.
- **Dark Theme Nativo:** Paleta de cores focada no conforto visual (Blue Team / Infra).
- **Design Responsivo:** Layout adaptável para Desktop, Tablets e Mobile.
- **Cards Interativos:** Efeitos de hover e transições suaves nos projetos e habilidades.
- **Visualização de Dados (JSON):** Bloco de código estilizado apresentando o perfil profissional e stack técnica.
